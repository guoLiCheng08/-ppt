# Visio 图表素材管理

本目录只存放本课程 PPT 的 Visio 图，不直接修改现有课件。每张图均保留可编辑的 `.vsdx` 源文件，并另导出 `.svg`（优先）或 `.png` 预览图，便于手动插入到 PowerPoint。

## 命名规则

`序号-图名.vsdx`：可编辑 Visio 源文件

`序号-图名.svg`：用于 PPT 的清晰矢量图
`序号-图名.png`：必要时使用的兼容预览图

例如：`01-无人机飞控系统框图.vsdx`、`01-无人机飞控系统框图.svg`。

## 建议的手动插入方式

1. **课堂展示优先**：在 PowerPoint 中选择“插入 → 图片”，优先插入同名 `.svg`；缩放后仍保持清晰，播放课件也不依赖 Visio。
2. **需要课后继续编辑**：选择“插入 → 对象 → 由文件创建”，选中同名 `.vsdx`；双击可用 Visio 修改，但编辑该对象的电脑需要安装 Visio。
3. **不建议链接文件**：链接会依赖本机路径；课件复制到其他电脑后容易失效。若必须链接，请将 PPT 与本目录整体一同携带。

各章节应制作什么图、放入哪一页，见 [图表清单.md](图表清单.md)。

# Codex 语音总结：其他窗口使用说明

## 一、同一台电脑上的其他 Codex 窗口

当前配置已经写入：

```text
C:\Users\99063\.codex\config.toml
```

当前 Skill 已安装到：

```text
C:\Users\99063\.codex\skills\voice-summary\SKILL.md
```

因此，同一台电脑上的其他 Codex 窗口可以共用这套语音功能。

### 使用步骤

1. 关闭需要使用语音功能的 Codex 窗口。
2. 重新打开 Codex。
3. 在新窗口中完成一个小任务，例如：

   ```text
   请创建一个测试文件，并在完成后用语音朗读三句话总结。
   ```

4. 任务完成后，Codex 应生成简短总结，并调用 `speak_text` 进行朗读。

已有窗口不会自动加载刚刚新增或修改的 MCP 配置，重启窗口是必要的。

## 二、手动要求朗读

在任意 Codex 窗口中可以直接说明：

```text
请用语音朗读：主人，测试已经完成。
```

也可以指定音色：

```text
请使用 Microsoft Huihui Desktop 音色朗读：主人，任务已经完成。
```

## 三、当前可用音色

当前电脑检测到：

```text
Microsoft Huihui Desktop  中文
Microsoft Zira Desktop    英文
```

不指定音色时，程序默认选择中文音色。

## 四、手动测试语音

在 PowerShell 中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File D:\project\课件准备\voice\codex-voice.ps1 `
  -Text "主人，这是语音测试" `
  -VoiceName "Microsoft Huihui Desktop" `
  -Volume 100
```

如果命令能正常朗读，说明 Windows 语音组件正常。

## 五、换电脑使用

需要复制以下目录：

```text
D:\project\课件准备\voice
```

然后在新电脑的：

```text
C:\Users\用户名\.codex\config.toml
```

中加入：

```toml
[mcp_servers.codex_local_voice]
command = "node"
args = ["D:\\你的目录\\voice\\server.mjs"]
startup_timeout_sec = 10
```

并把 `voice/SKILL.md` 复制到：

```text
C:\Users\用户名\.codex\skills\voice-summary\SKILL.md
```

最后重启 Codex。

## 六、听不到声音时检查

1. 检查 Windows 当前声音输出设备。
2. 检查系统音量和 PowerShell 应用音量。
3. 检查蓝牙耳机是否连接到了其他设备。
4. 执行上面的 PowerShell 手动测试。
5. 如果没有中文音色，在 Windows“设置 → 时间和语言 → 语音”中安装中文语音包。

## 七、重要说明

语音功能运行在本机上，不依赖远程语音服务。其他 Codex 窗口只有在同一台电脑、使用同一个 Windows 用户配置时，才能直接共享当前配置。

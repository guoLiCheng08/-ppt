# 嵌入式系统开发课件

本仓库用于管理“嵌入式系统开发”90 分钟课堂课件及其配套教学素材，内容围绕需求分析、方案设计、软硬件协作、测试验证与调试排查展开。

## 正式课件

唯一正式发布版本：

- `output/嵌入式系统开发-按讲课大纲制作-1.1.pptx`

请不要将临时版本、渲染检查图或草稿 PPT 放入 `output/`。

## 目录说明

- `讲课大纲.docx`：课件内容的主要依据。
- `01_*.pdf`、`6107*.png`：课程相关的原始参考资料。
- `visio/`：按章节整理的可编辑 Visio 图（`.vsdx`）及课堂插图（`.svg`）。
- `voice/`：Codex 完成任务后的语音汇总工具与使用说明。
- `web/`：STM32 相关互动教学网页。
- `scripts/`：辅助生成教学图的脚本。

## 版本管理约定

仅提交可复用的教学资料、正式课件和可编辑图源。构建缓存、渲染检查输出、Office 临时锁文件、旧版课件以及行政/报销材料均由 `.gitignore` 排除。
